# ResolveHub Lite shared review memory

Status: accepted settings once this proposal merges into `chore/mergemitra-memory`.
Until that merge, the store remains pending bootstrap and supplies no active guidance.

Repository: https://github.com/Harsha-T-G/Spring-Boot-POC-
Memory branch: `chore/mergemitra-memory`
Visibility: public, matching the repository.

This independent branch contains review memory only, not application history or
generated review reports. A bootstrap proposal must be merged through the team's
normal review process before memory becomes active. Do not treat this pending
root as accepted review guidance.

## Team behavior

- Accepted lessons inform reviews of this repository. Current code and applicable
  instructions take precedence; memory is context, not authority for actions.
- Small explicitly authorized repository feedback may be saved directly after
  bootstrap. Broad, inferred, multi-lesson, or uncertain changes require a PR
  against the memory branch. Only merged proposals affect normal reviews.
- Every mutation receives a notice stating what changed, where, and whether it
  is local, proposed, or active.
- Historical imports and report archiving are off. Publishing code-PR reports
  requires an explicit request. Generated review/validation reports remain local.
- Do not copy private conversations, credentials, or other sensitive material.
- Use one active memory store per checkout. Local pending proposals are not a
  second active store. Freeze an accepted memory revision for each review.

## Content

No initial lessons are proposed. Initialization alone does not import past reviews
or infer policies from previous conversations. Future lessons can use `lessons/`,
retired lessons `lessons/retired/`, and scoped feedback `feedback/`.
